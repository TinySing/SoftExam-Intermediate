# 前言与资料说明

## 你的目标

报考资格：**系统集成项目管理工程师（中级）**。

目标不是把教材从头背完，而是建立一条能用于选择题和案例题的主线：

> 需求 → 范围 → 进度 → 成本 → 质量 → 资源 → 沟通/干系人 → 风险 → 采购 → 变更 → 验收/收尾

## 推荐学习顺序

### 第一遍：搭框架

读 [[01-精华知识点/09-项目管理概论]]，再读启动、规划、执行、监控、收尾五个过程组。第一遍只求知道每个过程解决什么问题。

### 第二遍：补技术基础

按顺序阅读第 1～8 章。遇到完全陌生的计算机术语，不追求深入到开发工程师程度，只掌握定义、作用、典型场景和优缺点。

### 第三遍：专项记忆

使用 `02-计算与专项` 里的公式、49 个过程、输入输出和工具表，建立快速检索能力。

### 第四遍：案例训练

先背通用答题结构，再按“问题—依据—措施—结果”练习。案例答案要写成阅卷人能逐点给分的短句。

### 新增高频资料怎么用

老师新增的四色版资料适合在章节学习后快速回看，不建议把它当成另一套教材从头抄录。先看 [[00-开始复习/02-高频重点速查]]，按章节进入对应笔记，再打开 `new/` 中的原 PDF 复习标色关键词、助记和重复题号。

## 每次学习的固定流程

1. 预习：先看本节的“必须掌握”和“易错点”。
2. 理解：读正文，尝试用自己的话解释。
3. 记忆：合上页面复述清单或公式。
4. 练习：做题并标记错因。
5. 回收：把真正容易忘的内容写入自己的错题笔记。

## 什么需要背，什么不需要背

| 内容 | 方法 |
| --- | --- |
| 过程组、知识领域、49 个过程 | **必须背**，这是全科导航图 |
| 公式、指标、输入输出中的高频清单 | **必须背**，结合题目记 |
| 法律名称、标准名称、核心原则 | **必须背关键词**，不必背大段原文 |
| 技术概念和架构 | **理解优先**，会判断场景和优缺点 |
| 案例措施 | **背结构和关键词**，不要背整段范文 |

## 你现在只需要记住的三句话

- [ ] 先搭项目管理主线，再补技术基础。
- [ ] 短清单直接背；长清单按链接跳转分块背。
- [ ] 每学一节必须做题或写案例，不要只看笔记。

## 笔记规则

- 新概念用一句话定义，后面补“作用/场景/区别”。
- 一段只表达一个意思；超过 4 行就拆成列表。
- 公式单独成行，变量写清楚。
- 例题必须有“判断依据”，不能只写答案。
- 新增资料放到对应章节；暂时不知道放哪里，就先放在 `04-附录`，后续再归档。
- 老师的高频 PDF 保留原版；需要长期复习的内容只把索引、助记和自己的错因整理进 Markdown，避免维护两份正文。
