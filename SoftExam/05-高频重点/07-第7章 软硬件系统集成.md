# 第 7 章 软硬件系统集成

> 来源：`new/中级高频重难点考点详解-四色版（第7章：软硬件系统集成）.pdf`。

## 1. 系统集成概念

系统集成通常包括软件集成、硬件集成、网络集成、数据集成和业务应用集成。

系统集成以信息集成为目标，以功能集成为结构，以平台集成为基础，以人员集成为保证。核心不是简单安装设备，而是让不同厂商、不同技术和不同业务系统形成可运行、可测试、可验收的整体。

典型特点：参与队伍大且连续性不强；专业人员多元；承包商和服务组织分散；需要软硬件研制或适配；采用新技术多；实施和运维复杂。

## 2. 网络集成

网络集成包括传输、交换、安全、网管和服务子系统。

- 传输子系统：光纤、双绞线、同轴电缆、无线电波、微波和红外线等。
- 电路交换：先建立专用线路，传输稳定、时延小，但利用率低。
- 报文交换：以完整报文存储转发，线路利用率较高，但时延较大。
- 分组交换：拆成较小分组存储转发，利用率高、时延和费用较低。
- 混合交换：同时使用电路交换和分组交换，ATM 是典型例子。
- 安全子系统：防火墙、加密、访问控制。
- 网管子系统：监控运行、发现瓶颈、定位故障和优化性能。

## 3. 基础软件与应用集成

操作系统常考进程管理、存储管理、设备管理、文件管理和作业管理。

中间件位于操作系统和应用之间，为通信、消息、事务、数据访问和服务治理提供通用能力，帮助屏蔽底层差异。

应用集成常见技术包括 CORBA、COM/DCOM/COM+、.NET 和 J2EE。选择题重点看适用环境、通信方式、组件模型和分布式能力。

## 4. 案例关键词

系统集成项目答题按：需求与边界 → 总体设计 → 采购和准备 → 安装配置 → 接口联调 → 测试试运行 → 培训移交 → 验收运维。

看到接口不通、版本不一致、联调失败：写接口标准、版本基线、环境隔离、联调计划、测试数据、问题闭环和回退方案。
