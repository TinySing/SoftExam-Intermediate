# 第 2 章 信息技术发展

> 来源：`new/中级高频重难点考点详解-四色版（第2章：信息技术发展）.pdf`。

## 1. OSI 与常见协议

七层顺序：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。助记：**物联网传话，表用**。

常见协议归类：

- 物理层：FDDI、RS-232、V.35、RJ-45。
- 数据链路层：HDLC、SDLC、PPP、ATM、IEEE 802。
- 网络层：IP、IPX、ICMP、IGMP、ARP。
- 传输层：SPX、UDP、TCP。
- 会话层：RPC、SQL、NFS。
- 表示层：ASCII、HTML、GIF、JPEG、MIDI。
- 应用层：FTP、SMTP、HTTP、SNMP、Telnet。

TCP 面向连接、可靠、全双工；UDP 无连接、开销小、速度快但可靠性弱。FTP 基于 TCP，TFTP 基于 UDP且不提供存取授权和认证。

## 2. 存储与数据仓库

- 存储可按服务器类型分为封闭系统存储和开放系统存储。
- 存储虚拟化把一个或多个网络的存储资源整合为统一资源，是云存储的重要基础。
- 数据仓库面向主题、集成、相对稳定并反映历史变化，主要用于分析和决策，不等同于业务数据库。

## 3. 信息安全技术

- 加密把明文转换为密文，解密把密文还原为明文。
- 对称加密加解密使用同一密钥，速度快；非对称加密使用公钥和私钥，适合身份认证、密钥交换和数字签名。
- 数字签名重点保证身份认证、完整性和不可否认性；不等同于保密传输。
- 防火墙控制网络边界访问；入侵检测重在发现；入侵防御能够主动阻断或处理。
- Web 威胁重点关注注入、跨站脚本、身份认证缺陷、访问控制缺陷和敏感信息泄露。

## 4. 新一代信息技术

- 物联网三层：感知层、网络层、应用层，助记：**感—网—用**。
- 云计算特征：资源池化、按需自助、广泛网络访问、快速弹性和可计量服务。
- 大数据常考 5V：规模大、速度快、类型多、价值密度低、真实性要求高。
- 区块链重点：分布式账本、共识机制、密码学、不可篡改和可追溯。
- 人工智能重点：机器学习、深度学习、知识表示、推理和自然语言处理。
- 虚拟现实重点：沉浸性、交互性和构想性。
