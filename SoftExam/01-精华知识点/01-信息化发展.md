# 第 1 章 信息化发展

> [!important] 本章定位
> 选择题常考定义、特征和发展方向；遇到数字政府、数字经济、工业互联网等材料题，重点写“数据驱动、业务协同、平台支撑、安全保障”。

## 1. 信息与信息化

### 信息是什么

信息是对客观事物状态、特征和变化的反映。数据经过加工、解释并对决策产生价值后，才形成有用信息。

信息的常见特征：

- 客观性：来源于客观事物，但解释可能受主观因素影响。
- 普遍性：存在于自然、社会和思维活动中。
- 无限性：信息可以不断产生、传播和利用。
- 动态性：会随时间、环境和主体变化。
- 依附性：需要依附于载体才能传递和存储。
- 共享性：同一信息可被多个主体使用，通常不会因共享而消失。
- 可传递性、可处理性、可变换性：能够传输、加工和转换为其他表现形式。

> [!warning] 易错
> 信息不是物质，也不是能量；数据是信息的表现形式或记录载体，二者不能简单画等号。

### 信息质量

高质量信息通常具有：准确、完整、及时、可靠、相关、可验证、经济和安全等属性。题目问“天气数据不准确、报表缺字段、信息泄露”，分别对应质量或安全问题。

### 信息系统

信息系统是由人员、设备、软件、数据、流程和网络等要素组成的，以收集、处理、存储、传输和输出信息来支持组织目标的系统。

```text
输入 → 处理 → 输出
       ↑    ↓
     控制 ← 反馈
```

信息系统的基本功能：

1. 信息采集。
2. 信息存储。
3. 信息处理。
4. 信息传输。
5. 信息输出与利用。

### 信息传输模型

信息从产生到被接收，通常经过以下环节：

```text
信源 → 编码器 → 信道 → 译码器 → 信宿
                    ↑
                   噪声
```

- 信源：产生信息的实体。
- 编码器：把信息转换成适合传输的信号，也可以包含压缩、调制和加密设备。
- 信道：传送信息的通道，可以是逻辑通道，也可以是光纤、双绞线、移动网络等物理通道。
- 译码器：把信道传来的信号还原成信宿可以接收的信息。
- 信宿：信息的接收者或归宿。
- 噪声：传输过程中的干扰，可能来自系统的任何层次。

> [!important] 必背
> 信息系统性能的关键在于编码器和译码器。有效性强调传输的信息量，可靠性强调接收信息与发送信息的一致程度。

### 信息系统生命周期

信息系统生命周期通常包括：

```text
系统规划 → 系统分析 → 系统设计 → 系统实施 → 运行维护 → 消亡/退役
```

软件生命周期常见阶段是可行性分析与开发计划、需求分析、概要设计、详细设计、编码、测试、维护。不要把“项目生命周期”和“信息系统生命周期”混为一谈。

## 2. 信息化

信息化是充分利用信息技术、开发利用信息资源、推动组织和社会现代化的过程。它不只是“买电脑、上系统”，还包括业务流程、组织方式、治理机制和人员能力的变化。

信息化的基本内涵：

- 信息资源成为重要资源。
- 信息技术成为重要工具和基础设施。
- 数字化、网络化、智能化成为发展方向。
- 组织通过数据和系统提高决策、协作和服务能力。

> [!tip] 理解
> 信息化解决“如何利用信息和技术改变业务”；信息系统是实现这种改变的具体载体。

## 3. 现代化基础设施

### 新型基础设施

新型基础设施以信息网络为基础，面向数字化、网络化、智能化需求，主要包括：

- 信息基础设施：通信网络、数据中心、云平台、算力设施。
- 融合基础设施：智慧交通、智慧能源、工业互联网等与传统设施融合。
- 创新基础设施：支撑科学研究、技术研发和产业创新的设施。

### 工业互联网

工业互联网连接人、机、料、法、环、数据和服务，通过网络、平台、数据分析和安全体系支撑工业生产。

典型层次可理解为：

```text
设备/感知层 → 网络层 → 平台层 → 应用层
                 ↘ 安全与数据治理贯穿全层
```

重点能力：设备连接、数据采集、边缘处理、平台协同、工业应用、预测维护和生产优化。

### 城市物联网

通过传感器、通信网络、平台和应用连接城市设施，服务交通、能源、公共安全、环境和政务。案例中要注意数据共享、跨部门协同、隐私保护和系统可靠性。

## 4. 产业现代化

- 农业农村现代化：传感器、遥感、物联网和数据分析支持精准农业。
- 工业现代化：自动化、数字化车间、工业互联网和智能制造提高柔性与效率。
- 服务现代化：线上线下融合、平台化服务、智能客服和数据驱动运营。

### 智能制造成熟度

智能制造能力成熟度通常分为五级，由低到高为：

1. 规划级：规划智能制造基础和条件，核心业务实现流程化管理。
2. 规范级：利用自动化和信息技术改造业务，实现单一业务活动的数据共享。
3. 集成级：装备、系统和业务活动实现集成，跨业务共享数据。
4. 优化级：利用数据挖掘形成知识和模型，对业务进行预测和优化。
5. 引领级：持续驱动业务创新，实现产业链协同并形成新的制造模式。

## 5. 数字中国

### 数字经济

以数据资源和数字技术为重要驱动力，促进产业数字化和数字产业化。考试中要区分：

- 数字产业化：发展数字技术、产品、服务和基础设施产业。
- 产业数字化：用数字技术改造传统产业。

### 数字政府

以公共数据和数字技术提升政府治理、公共服务和跨部门协同能力。重点是业务协同、数据共享、统一平台、依法治理和安全保障。

### 数字社会与数字生态

数字社会关注教育、医疗、养老、交通等公共服务；数字生态关注政府、企业、社会和公众共同参与，形成开放协同、绿色安全的数字环境。

## 6. 数字化转型与元宇宙

### 数字化转型

数字化转型不是单个系统上线，而是以业务战略为牵引，利用数字技术重构业务流程、组织能力、产品服务和经营模式。

建议用四层理解：

1. 数据基础：数据标准、质量、共享和安全。
2. 技术平台：云、网络、算力、中台和应用平台。
3. 业务重构：流程优化、协同和智能决策。
4. 组织治理：战略、人才、制度、文化和持续改进。

### 元宇宙

元宇宙是融合虚拟与现实、持续运行、多人参与的数字化空间概念，涉及扩展现实、数字孪生、人工智能、云计算、区块链和物联网等技术。

学习重点是技术组合和应用边界，不必死背营销式描述；题目问风险时，想到隐私、安全、身份、内容治理、沉浸体验和算力成本。
