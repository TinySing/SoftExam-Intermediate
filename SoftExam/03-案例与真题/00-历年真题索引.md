# 历年真题索引

## 选择题

1. 先做无答案版：原始 PDF 未随当前项目提供；可直接在题库系统中选择对应历年试卷练习。
2. 再看答案版：原始 PDF 未随当前项目提供；题库系统交卷后可查看答案与解析。
3. 错题回到对应章节 Markdown 笔记，不要只记选项。

## 案例题

1. 先做无答案版：原始 PDF 未随当前项目提供；可直接在题库系统中选择对应历年试卷练习。
2. 再看答案版：原始 PDF 未随当前项目提供；题库系统中可查看参考答案，提交后可使用 AI 辅助评分。
3. 案例答题方法：[[03-案例与真题/01-案例复习方法及答题技巧]]
4. 找问题专项：[[03-案例与真题/03-找问题题型]]

## 使用规则

- 选择题：按章节做，错题记录“错在哪里、正确边界是什么”。
- 案例题：先独立写，再按得分点补答案；每个得分点单独成句。
- 计算题：写公式、代入、结果和单位，不能只抄最终答案。
- 文件名标注“2026 年下”，实际题目年份以 PDF 内题面和答案说明为准。
