# 第 3 章 信息技术服务｜高频重点

## 1. 服务特征

服务四个基本特征：

- 无形性：服务难以像实物一样展示和储存，质量需要通过过程和结果评价。
- 不可分离性，也叫同步性：生产和消费通常同时发生，服务人员直接影响体验。
- 可变性，也叫异质性：服务质量会因人员、时间、地点和环境不同而变化。
- 不可储存性，也叫易逝性：服务能力不能像商品一样库存。

助记：**不可不无**，即不可储存、不可分离、不可变成同一质量、无形。

## 2. IT 服务内涵

IT 服务组成要素：人员、过程、技术、资源，助记：**PPTR**。

服务形态包括 IT 咨询、设计与开发、信息系统集成、数据处理和运营、智能化服务及其他 IT 服务。

服务外延包括：

- 基础服务：咨询设计、开发、集成实施、运行维护、云服务和数据中心。
- 技术创新服务：智能化服务、数字服务、数字内容处理和区块链服务。
- 数字化转型服务：成熟度推进、评估评价、数字化监测预警。
- 业务融合服务：信息技术与政务、教育、应急、业财等行业融合。

## 3. IT 服务生命周期

常见主线：规划设计、部署实施、服务运营、持续改进。每个阶段都要有目标、责任、过程、指标、记录和改进闭环。

## 4. 服务质量评价

服务质量评价要关注需求满足程度、服务级别、可用性、可靠性、响应速度、处理效率、客户满意度和持续改进。

第三方评价应保持相对独立，以服务质量需求、合同、标准和客观数据为依据，不能只听服务方口头说明。

## 5. 案例关键词

看到服务投诉增加、响应时间变长：写服务级别目标、监控指标、事件流程、责任人、升级机制、根因分析和持续改进。

看到运维依赖个人经验：写标准流程、知识库、岗位职责、培训、记录、审计和交接。
