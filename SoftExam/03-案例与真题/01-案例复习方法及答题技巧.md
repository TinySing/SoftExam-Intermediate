# 案例复习方法及答题技巧

## 案例题考什么

案例题不是考“背了一段标准答案”，而是考你能否把项目现场问题对应到正确的管理过程，并提出可落地的动作。

常见小问：

1. 找出项目管理中的错误或缺陷。
2. 解释某个过程、文档、指标或方法。
3. 根据材料计算进度、成本或风险。
4. 提出整改措施、补充流程或说明后果。

## 必须背的答题骨架

- [ ] 找问题：事实+违反的过程/原则+造成的影响。
- [ ] 提措施：记录/补文档→影响分析→审批→执行→验证→归档。
- [ ] 问原因：直接原因+管理原因+制度/流程原因+技术或环境原因。

## 通用答题结构

### 问题题

```text
问题事实 + 违反的原则/过程 + 造成的影响
```

例：项目成员未经评审直接修改基线，违反整体变更控制要求，导致计划、成本和验收依据不一致。

### 措施题

```text
立即止损 + 补齐文档/审批 + 执行控制 + 跟踪验证 + 经验沉淀
```

### 原因题

```text
直接原因 + 管理原因 + 制度/流程原因 + 技术或环境原因
```

不要把“原因”写成重复的解决方案。

## 读题顺序

1. 先读小问，判断需要找问题、解释、计算还是措施。
2. 再读案例，圈出人物、时间、文档、审批、基准、变更和异常数据。
3. 把事实归入知识领域：范围、进度、成本、质量、资源、沟通、风险、采购、干系人。
4. 每个得分点单独编号作答。

## 时间分配

按准考证上的实际考试时长安排。训练时可以采用：

- 10%：读题和标关键词。
- 70%：按小问作答。
- 20%：检查漏点、公式、单位和答题顺序。

> [!warning] 不要在一道计算题上耗尽时间
> 先把能确定的文字题得分点写出来，再回头处理复杂计算。

## 案例常用答题句式

- “应先……，由……负责，经……审批后再……”
- “应将该需求记录在……，分析对范围、进度、成本、质量和风险的影响。”
- “应依据已批准的……，通过……过程进行控制。”
- “发现偏差后，应分析根因，提出纠正措施；必要时提交变更请求。”
- “完成后应由客户/授权相关方按验收标准确认，并形成书面记录。”

## 训练闭环

每道案例做完后记录：

| 项目 | 内容 |
| --- | --- |
| 我漏掉的点 | 例如漏写变更审批 |
| 正确依据 | 例如基准不能直接修改 |
| 可复用句 | 下次可以直接套用的规范表述 |
| 再练时间 | 例如 3 天后重做 |

> [!important] 评分思维
> 阅卷按关键词和得分点给分。答案应短、准、分点，不要写大段空泛的项目管理口号。
