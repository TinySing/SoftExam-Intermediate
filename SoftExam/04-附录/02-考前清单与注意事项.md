# 考前清单与注意事项

## 一周前

- [ ] 确认准考证上的具体科目、批次、时间和考点。
- [ ] 规划路线，预留入场、安检和找考场时间。
- [ ] 完成至少 1 次整套模拟，按真实机考节奏执行。
- [ ] 复习公式：[[02-计算与专项/01-计算专题]]。
- [ ] 复习 49 个过程：[[02-计算与专项/03-49个过程定义及作用]]。
- [ ] 复习案例通用措施：[[03-案例与真题/03-找问题题型]]。

## 前一天

- [ ] 准备身份证原件和准考证。
- [ ] 按准考证和考场规则准备允许携带的文具及其他用品。
- [ ] 确认交通、天气和早餐。
- [ ] 不再学习冷门新知识，保证睡眠。

## 考场内

- [ ] 按官方要求提前到场并登录；迟到和入场要求以准考证及考场规则为准。
- [ ] 电子设备、通讯工具不要带到座位。
- [ ] 先确认登录信息和考试科目。
- [ ] 基础题先易后难，标记不确定题。
- [ ] 案例题按小问逐点作答，答案分行。
- [ ] 计算题写公式、过程、单位。
- [ ] 交卷前检查漏答和误选。

## 案例答题自检

- [ ] 是否先写出题干中的事实问题，以及违反的过程或原则？
- [ ] 每条措施是否写清动作、责任人、时间或文档，而不是只写“加强管理”？
- [ ] 计算题是否写出公式、代入、结果和单位？
- [ ] 长篇案例清单：跳转 [[03-案例与真题/02-案例文字题总结]]。
- [ ] 是否写出违反的管理原则或过程要求？
- [ ] 是否给出具体动作、责任人、文档或审批机制？
- [ ] 是否覆盖范围、进度、成本、质量、风险、沟通等影响？
- [ ] 是否避免只写“加强管理”“提高意识”这类空话？
