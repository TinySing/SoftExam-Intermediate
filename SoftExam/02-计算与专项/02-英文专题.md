# 英文专题

## 做题方法

1. 先看问题和选项，判断考的是过程、文档、指标还是技术名词。
2. 圈出题干中的动作词：`plan`、`identify`、`control`、`monitor`、`close`。
3. 优先按项目管理语境翻译，不按普通词义硬译。
4. 看见缩写先回忆中文全称，再判断选项。

- [ ] `project charter`=项目章程；`scope baseline`=范围基准；`risk register`=风险登记册。
- [ ] `initiating / planning / executing / monitoring and controlling / closing`=启动/规划/执行/监控/收尾。
