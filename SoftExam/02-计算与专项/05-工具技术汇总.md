# 高频工具与技术

## 直接背这些

- [ ] 帕累托图=找少数主要原因；因果图=找根因；控制图=看过程是否稳定；散点图=看变量相关；直方图=看数据分布。
- [ ] 定性风险分析=排序优先级；定量风险分析=量化风险影响。
- [ ] 快速跟进=并行开展活动；赶工=增加资源或加班；快速跟进增加返工风险，赶工增加成本。
- [ ] 长工具表按本页“需求与范围、质量、风险、计划与估算、沟通与团队”分组背。

## 需求与范围

| 工具 | 适用场景 |
| --- | --- |
| 访谈 | 深入了解单个或少量干系人的需求 |
| 问卷/调查 | 面向大量对象快速收集信息 |
| 头脑风暴 | 快速产生大量想法，先发散后筛选 |
| 焦点小组 | 由主持人组织目标用户讨论需求 |
| 观察 | 通过实际工作过程发现隐性需求 |
| 原型法 | 先做可视化模型，帮助确认需求 |
| 标杆对照 | 与同类项目或组织实践比较 |
| 多标准决策分析 | 按多个标准比较方案 |
| 分解 | 把范围或工作逐层拆成可管理部分 |

## 质量工具

- **因果图**：从人、机、料、法、环、测等方面分析根因。
- **控制图**：观察过程是否稳定，是否超出控制界限。
- **流程图**：展示步骤、分支、输入输出和瓶颈。
- **直方图**：展示数据分布。
- **帕累托图**：按影响大小排序，寻找少数主要原因。
- **散点图**：判断两个变量之间是否可能相关。
- **核查表**：结构化记录数据或缺陷。
- **审计**：独立、系统地检查过程是否符合要求。

## 风险工具

| 工具 | 重点 |
| --- | --- |
| SWOT | 优势、劣势、机会、威胁 |
| 假设条件和制约因素分析 | 检查项目成立的前提和限制 |
| 概率—影响矩阵 | 按概率和影响排序风险 |
| 敏感性分析 | 看哪个不确定因素对目标影响最大 |
| 决策树 | 比较方案和风险结果的期望值 |
| 模拟 | 通过多次试验估计可能结果范围 |

## 计划与估算工具

- **滚动式规划**：近期工作详细规划，远期工作保持较粗粒度，信息明确后再细化。
- **专家判断**：使用有经验人员的知识，注意记录依据和偏差。
- **类比估算**：参考类似项目，速度快但准确性依赖相似度。
- **参数估算**：用历史数据和参数模型计算，适合数据质量较高的场景。
- **自下而上估算**：先估算底层工作，再向上汇总，准确但耗时。
- **三点估算**：用 O/M/P 降低单点估算的不确定性。

## 沟通与团队工具

- 沟通模型：编码 → 传递 → 解码 → 确认；噪声会造成误解。
- 沟通方法：互动式、推式、拉式；按信息紧急程度和受众选择。
- 会议：明确目的、议程、参与人、决策、行动项和责任人。
- 冲突处理：撤退/回避、缓和/包容、妥协/调解、强迫/指导、合作/解决问题。

> [!important] 案例答题关键词
> 不能只写“加强沟通”。要写清楚沟通对象、频率、渠道、责任人、记录方式和升级路径。
