# 49 个项目管理过程：定义与作用

> [!important] 背诵主线
> 启动定方向，规划定方案，执行做事情，监控找偏差并批准变更，收尾完成移交。

## 背诵方法

- [ ] 第一轮只背过程组和数量：启动 2、规划 24、执行 10、监控 12、收尾 1。
- [ ] 第二轮按表背每个过程的“动作+目的”；完整清单就是本页内容。
- [ ] 第三轮用 [[00-开始复习/01-考试说明与学习计划]] 和案例题复述，能说出“什么时候用、解决什么问题”。

## 启动过程组（2 个）

| 过程 | 作用 |
| --- | --- |
| 制定项目章程 | 正式授权项目，明确目标、边界、经理权限和高层信息 |
| 识别干系人 | 识别受项目影响或能影响项目的人，记录其影响和参与策略 |

## 规划过程组（24 个）

| 领域 | 过程 |
| --- | --- |
| 整合 | 制定项目管理计划 |
| 范围 | 规划范围管理、收集需求、定义范围、创建 WBS |
| 进度 | 规划进度管理、定义活动、排列活动顺序、估算活动持续时间、制定进度计划 |
| 成本 | 规划成本管理、估算成本、制定预算 |
| 质量 | 规划质量管理 |
| 资源 | 规划资源管理、估算活动资源 |
| 沟通 | 规划沟通管理 |
| 风险 | 规划风险管理、识别风险、实施定性风险分析、实施定量风险分析、规划风险应对 |
| 采购 | 规划采购管理 |
| 干系人 | 规划干系人参与 |

## 执行过程组（10 个）

| 过程 | 作用 |
| --- | --- |
| 指导与管理项目工作 | 按计划实施工作，产出可交付成果，提出变更 |
| 管理项目知识 | 使用已有知识并沉淀新知识，促进复用 |
| 管理质量 | 把质量要求转化为可执行的过程改进活动 |
| 获取资源 | 获取团队成员、设备、材料、设施等资源 |
| 建设团队 | 提升能力、互动质量和团队氛围 |
| 管理团队 | 跟踪绩效、解决冲突、管理变更和人员问题 |
| 管理沟通 | 按计划收集、生成、分发和维护项目信息 |
| 实施风险应对 | 执行已批准的风险应对措施 |
| 实施采购 | 获取卖方报价、选择卖方并建立协议 |
| 管理干系人参与 | 沟通协作、处理问题，满足干系人需求和期望 |

## 监控过程组（12 个）

| 过程 | 作用 |
| --- | --- |
| 监控项目工作 | 从项目整体层面跟踪状态、预测趋势并报告 |
| 实施整体变更控制 | 评审、批准/拒绝、记录和管理变更 |
| 确认范围 | 正式验收已完成的可交付成果 |
| 控制范围 | 监督范围状态，管理范围基准变更 |
| 控制进度 | 监督进度状态，管理进度基准变更 |
| 控制成本 | 监督成本状态，管理成本基准变更 |
| 控制质量 | 检查成果是否符合质量要求 |
| 控制资源 | 确保实物资源按计划获得和使用 |
| 监督沟通 | 确保沟通满足项目和干系人需要 |
| 监督风险 | 跟踪既有风险、识别新风险、评价应对有效性 |
| 控制采购 | 管理合同关系、监督合同绩效、处理变更和索赔 |
| 监督干系人参与 | 监督干系人关系和参与策略，调整参与方式 |

## 收尾过程组（1 个）

| 过程 | 作用 |
| --- | --- |
| 结束项目或阶段 | 完成验收、移交、归档、经验总结和资源释放，正式结束项目 |

## 高频混淆

| 容易混淆 | 区别 |
| --- | --- |
| 管理质量 / 控制质量 | 管理质量偏过程改进；控制质量偏成果检查 |
| 确认范围 / 控制质量 | 确认范围是客户/相关方验收；控制质量是技术和质量检查 |
| 监控项目工作 / 实施整体变更控制 | 前者看整体状态和趋势；后者处理具体变更请求 |
| 规划风险应对 / 实施风险应对 | 前者制定策略和措施；后者真正执行措施 |
| 规划采购管理 / 实施采购 / 控制采购 | 设计采购方案；选卖方签协议；监督合同履行 |
| 识别干系人 / 监督干系人参与 | 启动时识别和分析；执行后持续跟踪参与效果 |
